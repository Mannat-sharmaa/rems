Academic Project Overview

Real Estate Management System (REMS)

A comprehensive Database Management System (DBMS) capstone project developed for the 5th Semester B.Tech AI & Data Science curriculum.

🎯 Project Objectives

To design and implement a production-grade relational database architecture solving complex concurrency, data integrity, and analytical reporting challenges in real estate commerce. Moving far beyond basic CRUD tutorials, the system demonstrates:

  • Strict 3NF Normalization: Elimination of insertion, update, and deletion anomalies across 12 relational entities.
  • ACID Transactions: Atomic property reservations with row-level locks (`SELECT FOR UPDATE`) preventing double-booking race conditions.
  • Automated Triggers: Real-time status transitions (`Available` → `Booked` → `Sold` / `Rented`) and rating constraints.
  • Stored Procedures: Parameterized search routines and commission calculators for agents.
  • Database Views: Pre-aggregated stakeholder summaries and performance ledgers.

Frontend Stack

Vanilla HTML5, Modern CSS3 variables, JavaScript ES6+, Custom cursor interpolation, Responsive Glassmorphism Design, and Canvas 3D rendering.

Backend Stack

Node.js, Express.js REST APIs, JWT Session Authentication, Bcrypt Password Hashing, and Structured MySQL error management.

Database Engine

MySQL 8.x / MariaDB 10.x compatible with MySQL Workbench, InnoDB transactional storage engine, Foreign Keys, and Delimited Triggers.
